# Yohaku 余白

The space left on purpose. A quiet token on Ethereum, launched on Programmable.

- 1,000,000,000 supply, fixed. No team allocation.
- 5% on every trade: 4.7% creator fee + 0.3% Programmable. Fixed in the pool's hook.
- Liquidity locked forever. Programmable launch protection: 99% opening fee falling to 5% over 30 s, 2% wallet cap for 5 minutes.
